# Hardwood Loop API

A court-ready delivery format for loop literacy.

## 1) Ball Drop

"Everything in your day is loops: breath, dribble, shot prep, recovery."

## 2) Circle vs Spiral

"Some loops keep you stuck. Some loops level you up."

## 3) Dashboard

"Feelings are dashboard lights, not your identity."

## 4) Controller

"Autopilot exists. Choice exists. Use the pause."

## 5) Sync

"Great teams synchronize rhythms. That is playable trust."

## Coach Notes

- Use one concept per session.
- Tie abstract language to a drill.
- Close each session with one next-loop commitment.
